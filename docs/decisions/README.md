# 决策记录（ADR）

每个关键技术选择写一个文件，编号递增，例如 `0001-real-data-source.md`。只记"当时为什么这么选"，写完不改；决定被推翻时，新写一条并注明取代关系。

## 模板

```markdown
# 000X 标题

- 日期：
- 状态：已采纳 / 已被 000Y 取代

## 背景
## 备选方案
## 决定
## 代价与风险
```
