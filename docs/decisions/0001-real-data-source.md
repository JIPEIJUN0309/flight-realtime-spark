# 0001 使用真实实时数据源 OpenSky，不用模拟或回放数据

- 日期：2026-10-16
- 状态：已采纳

## 背景

作品集项目最容易滑向"造一批假数据，证明管道能跑"。这样写出来的代码看不出真实数据源的问题：
限流、字段缺失、时区、数据延迟、认证方式变更，一个都碰不到。

## 备选方案

1. **自己造数据**：可控、可重复、不花额度。但会绕开所有真实工程约束。
2. **回放历史文件**：可重复，但仍不涉及采集合规和实时性。
3. **真实 API（OpenSky）**：有额度、有认证、有中断，所有约束都是真的。

## 决定

用 OpenSky REST API 的真实 ADS-B 状态数据，按 OAuth2 客户端凭证认证，欧州 90 平方度范围采集。

## 代价与风险

- 额度有限（每天 4,000 credits）：采集间隔和范围成了设计输入，见 0005。
- 数据源会变：2026 年 3 月 OpenSky 停用用户名密码认证，采集器不得不改造；这恰好是真实项目会遇到的。
- 现场演示受天气、空域、网络影响，数字会有波动，所以所有验收都记录"实测值 + 时间"。
